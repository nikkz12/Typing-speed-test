
# TypeMaster - Typing Speed Test

## About the Project
TypeMaster is a web-based typing speed test application developed using HTML, CSS and JavaScript.

It helps users measure their typing speed and accuracy through a 60-second typing challenge.

## Features
- 60-second countdown timer
- Ready-made practice paragraph
- Real-time typing speed calculation (WPM)
- Accuracy calculation
- Correct and incorrect character highlighting
- Restart and retry functionality
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using a browser or Live Server.
4. Click Start Test and begin typing.

## Project Structure
- index.html - Website structure
- style.css - Website design
- script.js - Application functionality
